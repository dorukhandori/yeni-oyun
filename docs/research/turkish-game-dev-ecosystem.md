# Türk oyun geliştirici ekosistemi — geniş tarama

**Tarih:** 2026-08-16  
**Bağlam:** Lotophagoi (Vite + Three.js, indie narrative/exploration, Steam/GitHub Pages hedefi)  
**Lotophagoi ile ilişki:** `docs/research/lotophagoi-problems-repo-solutions.md`

---

## 1. Executive özet

Türkiye oyun sektörü **iki katmanlı**:

| Katman | Kim | Lotophagoi’ye yakınlık |
|---|---|---|
| **Mobil dev** | Dream Games, Peak, Rollic, Good Job Games… | Düşük (puzzle/hyper-casual pipeline) |
| **PC / indie yükselişi** | Nokta, Phew Phew, TaleWorlds, yeni mikro stüdyolar | **Yüksek** |
| **Topluluk / altyapı** | ÜNOG, ATOM, GameDev.ist, Mobidictum, GGJ | **Yüksek** (playtest, görünürlük, mentor) |
| **Web / Three.js bireysel** | Az ama var (Lale, Zaman Makinesi, Prensesi Koru…) | **Çok yüksek** (stack eşleşmesi) |
| **AI oyun agent (TR)** | GameFactory, NAKRUF Logic, Agent Game Forge (TR readme) | Orta (fikir; stack farklı) |

**Kısa cevap:** Evet, Türk geliştirici ekosistemi **çok geniş** — ama Lotophagoi’nin stack’ine (browser Three.js + narrative) doğrudan denk gelen **stüdyo sayısı küçük**; asıl değer **topluluk + PC indie ağı + harita/platformlar**.

## 7. Lotophagoi için “kimi izlemeli, kime gitmemeli”

### Yüksek değer

1. **ÜNOG / Indie Core / İNOG** — playtest partneri, feedback, co-dev  
2. **Mobidictum Indie Spot + aylık TR indie listeleri** — çıkış görünürlüğü  
3. **GameDev.ist** — Steam sayfası / Xbox / pazarlama (Supermarket Simulator modeli)  
4. **indiestry Map / in-die Valley** — stüdyo kaydı + keşif  
5. **GGJ (YTÜ / ATOM)** — 48 saatlik prototip + ekip kurma  
6. **GitHub TR Three.js örnekleri** — Prensesi Koru (Vite+TS stack kanıtı)

### Orta değer

- **Phew Phew / Nokta** — Steam marketing case study (mekanik değil)  
- **GameFactory / AGF** — agent pipeline fikirleri (TR maintainer)  
- **TaleWorlds** — açık dünya sistem derinliği (C++/kendi motor, kod borçlanma yok)

### Düşük / dikkat

- **Mobil puzzle devleri** — AI asset pipeline farklı (2D sprite, UA, LiveOps)  
- **Roblox AI plugin’leri** — Lua stack; Lotophagoi ile overlap sınırlı  
- **Peak/Dream hiring pipeline** — triple-match tasarım kültürü, narrative web oyun değil

## 11. Sonuç

**Türk geliştirici ekosistemi var ve büyüyor** — ama Lotophagoi için anlamlı olan alt küme:

```
PC/indie stüdyolar + topluluklar (ÜNOG, GGJ, GameDev.ist)
  + az sayıda web/Three.js GitHub örneği
  + yükselen AI-agent oyun fabrikaları (GameFactory, AGF)
```

Mobil devlerin **başarısı** (Dream/Peak) Lotophagoi pipeline’ına taşınmaz; **Steam indie çıkış hikâyeleri** (Nokta, Phew Phew) ve **topluluk playtest** en pratik Türk kaynağıdır.

**Önerilen ilk adımlar (sahip):**

1. **indiestry Map**’e Lotophagoi / stüdyo satırı (çıkış yaklaşınca)  
2. **ÜNOG veya Indie Core**’da web playtest linki + feedback formu  
3. **Mobidictum** Türk indie listesine adaylık (dikey slice sonrası)  
4. **GGJ 2026** (YTÜ veya ATOM) — Lotus mekaniği 48 saat spin-off değil, hub kartı UX testi bile olabilir
